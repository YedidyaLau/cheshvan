# ליל שבת ויומה — הלכות שבת

עמוד לימוד ליחידה ב' (חשוון–כסלו): תשעה שבועות — הסימנים, מוקדי העיון והמקורות.

**הקובץ נגזר ואינו נערך כאן.** הוא נבנה מתוך ריפו פרטי על ידי
`build/publish_unit.py`, וכל תיקון נעשה שם. עריכה ידנית של `index.html`
תימחק בפרסום הבא.

סיכום אינו מקור. העמוד הוא מפת יסודות ואינו תחליף ללימוד מן הספרים.
